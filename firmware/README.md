# ESP32 控制代码

需要 ESP32 的 MicroPython 固件。上传 `CQU_fivebar_fixed.py`、`main.py`、`setup.py` 到设备根目录；不修改 boot.py。

分发默认 `main.AUTOSTART=False`、核心 `CALIBRATED=False`，上传后不会自动写字。导入模块也不创建PWM。其余配置沿用用户最新文件，均为设备相关参数，不能直接当通用标定：

- 左/右/抬笔信号：GPIO13 / GPIO14 / GPIO26。
- BOARD_CENTER=(13,65) mm；左右参考角90°，方向+1/-1，trim均0。
- 左右增益当前5.556μs/°，待各自两点测量；XY脉宽门限1000..2000μs。
- 抬笔40°、落笔5°，抬笔舵机独立映射与限位。
- 字框20mm、间隔2mm；名义书写20mm/s、空移30mm/s。
- 固件OFFSET_DEG=60°保持用户值；CAD证明偏置幅值45°，网页仅选择+45°观察侧。两者需要实物核对，不能把网页效果当固件已标定。

## 先做纯计算检查

在Thonny运行设备上的 setup.py，输入 `check 8` 或 `check CQU`。该命令不创建PWM，只报告几何、电气范围及首个拒绝点；不同目标可能被当前限位拒绝。

## 标定与试写

先卸笔、解除主动臂与舵机机械耦合，在 setup.py 用 `eleft 90` / `eleft 110`、`eright 90` / `eright 110` 选取安全的两点并量取实际几何角；若该小范围也不安全，应先调整机械安装。`calleft g90 g110`、`calright g90 g110` 只计算并打印映射参数，不自动改文件。将测得的零位、方向、增益写回核心配置，并实测板中心和独立抬落笔角度。确认后设 CALIBRATED=True，保持AUTOSTART=False，无笔空走通过再装笔试写。

手动一次：`import main; p = main.write('8')`；完成后需停机可调用返回对象的 `p.close()`或中断清理。启用上电单次书写之前，再确认整图预检和实际机械行程。BOOT只在启动窗口取消，不是运动急停。

三舵机使用独立稳压5V电源并与ESP32共地；USB给开发板单独供电。不要把舵机接到3.3V。

## 真实状态

代码具备分支校核、整图预检、逐笔抬落与20ms节拍。实机曾出现偏边、Y压缩，尚无最终精度/速度和整组CQU实写验收记录；擦除未实现。仓库保存的是可标定控制程序，不是上电即已标定的固件。
