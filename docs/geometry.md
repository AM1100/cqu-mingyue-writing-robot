# 结构与运动学

A=(0,0)，B=(25,0)mm；主动臂35mm×2，从动臂45mm×2，腕点到笔夹中心13mm。平面闭环2自由度由左右两路驱动，第三路带动整个五连杆俯仰抬笔。

正解：关节角→两肘点→两圆交点W→笔尖偏置P。逆解：将左从动臂与笔偏置合为等效连杆，求左角，再恢复W、求右角，固定分支后正解回代。

L_eff = sqrt(L4²+Lt²+2L4Lt cosδ)；gamma = atan2(Lt sinδ,L4+Lt cosδ)。

CAD网格中，两通孔心(0,0)、(45,0)，笔夹心约(54.1924,-9.1924)，因此腕孔到笔夹心偏移(9.1924,-9.1924)mm，长度13mm、夹角幅值45°。135°是从腕→肘方向计的补角，60°是V形夹口角。±45°由观察侧与安装定义决定。
